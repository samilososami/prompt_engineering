  1. Executive summary paragraph: total hosts, total ports, vulnerability counts
     by severity, total successful exploits, total elapsed time, overall security
     posture assessment.

  2. Complete network map table (all hosts, OS, open ports, risk level).

  3. Complete vulnerability registry (all CVEs found, sorted by CVSS descending).

  4. Complete exploitation results table.

  5. Full attack surface map per host (all vectors, priority-ordered by CVSS).

  6. Remediation table: one specific actionable recommendation per HIGH/CRITICAL
     finding, with priority (IMMEDIATE / SHORT-TERM / LONG-TERM).

  7. Time summary:
       Audit started:     <timestamp>
       Audit ended:       <timestamp>
       Total elapsed:     <Xh Ym Zs>
       Mode time limit:   <HARD_LIMIT or "none">
       Limit reached:     YES / NO

Print confirmation in $LANG that the audit log has been saved to:
  ~/auditor_agent/audit_<YYYY-MM-DD_HH-MM>.<WRITE_TYPE>
